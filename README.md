# Netro

Welcome to Netro!

## 🚀 Running the Website

To run the Netro website locally, follow these steps:

    cd Frontend
    npm install
    npm run dev

This will start the development server, typically available at:

    http://localhost:5173

## 📦 Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (comes with Node.js)
